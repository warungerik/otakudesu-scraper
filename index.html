Dokumentasi Otakudesu Scraper

Kode scraper anime bahasa Indonesia yang ringan, modular, dan siap pakai. Mendukung ekstraksi stream MP4 langsung, player iframe, mirror server, dan link download per resolusi.

🚀 Quickstart

Cukup simpan kode scraper ke dalam file otakudesu.js di project Anda. Tanpa perlu install library tambahan.

Contoh Import & Eksekusi
// Impor fungsi yang Anda butuhkan
import { getHome, getAnime, getEpisode, search } from './otakudesu.js';

// 1. Ambil anime terbaru di beranda
const home = await getHome();
console.log(home.ongoing);

// 2. Ambil detail anime
const anime = await getAnime('slime-s4-sub-indo');
console.log(anime.info.Judul, anime.episodes);

// 3. Ambil video nonton & download episode
const ep = await getEpisode('tenslem-s4-episode-21-sub-indo');
console.log('Stream MP4 Langsung:', ep.video);

📦 Daftar Fungsi Lengkap

Setiap fungsi mengembalikan format JavaScript Object / JSON murni yang mudah diolah.

async getHome()
Mengambil daftar anime yang sedang tayang (Ongoing) dan anime yang sudah tamat (Complete) di halaman depan.
Usage
import { getHome } from './otakudesu.js';

const { ongoing, complete } = await getHome();
Contoh Nilai Balik (Return JSON)
{
  "ongoing": [
    {
      "title": "Neko to Ryuu",
      "slug": "neko-ryuu-sub-indo",
      "episode": "Episode 11",
      "day": "Sabtu",
      "date": "06 Sep",
      "cover": "https://otakudesu.blog/wp-content/uploads/2026/07/157796.jpg"
    }
  ],
  "complete": [ ... ]
}
async getList(type = 'ongoing')
Mengambil seluruh daftar arsip anime ongoing atau anime tamat. Parameter: 'ongoing' atau 'complete'.
Usage
import { getList } from './otakudesu.js';

const ongoingList = await getList('ongoing');
const completeList = await getList('complete');
async search(query)
Mencari judul anime dari kata kunci yang diberikan. Mengembalikan judul, slug, genre, status, dan rating.
Usage

async getEpisode(slug)
Mengambil data streaming dan download episode. Fitur unggulan: otomatis mengekstrak file video Direct MP4 langsung (misal: cdn.odcloud.net) sehingga dapat diputar langsung di tag <video> tanpa iklan iframe.
Usage

const ep = await getEpisode('tenslem-s4-episode-21-sub-indo');

async resolveMirror(payload, nonce)
Mengubah server player alternatif (misalnya filedon, vidhide, mega) melalui sistem 2-step WordPress AJAX resolver milik situs asal.
Usage
import { getEpisode, resolveMirror } from './otakudesu.js';

const ep = await getEpisode('tenslem-s4-episode-21-sub-indo');
const server = ep.servers[0]; // contoh: filedon

// Dapatkan url embed baru
const result = await resolveMirror(server.payload);
console.log('Iframe Embed Baru:', result.iframe);
